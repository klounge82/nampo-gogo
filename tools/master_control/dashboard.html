  6. 큰/중간 오류 처리: 큰 오류는 즉시 개발 중단 후 해결, 중간 오류는 관련 본선 구간에서 처리.

  8. 오류 등급 상향 재분류: 보안·결제·포인트·Crash 영향 시 즉시 상위 오류(MAJOR/CRITICAL)로 재분류.
  9. 생산 DB 쓰기 산술 검산: 모든 DB 쓰기는 예상 Insert/Update/Delete 및 레저 수식을 산술 검산.
  10. 중복 실행 차단 (Idempotency): 고유 Idempotency Key로 중복 위험 작업 재실행 엄격 차단.
  11. 보고서 독립 검증: 완료보고서 표기를 과신하지 않고 관제실이 Git/DB/파일을 독립 자동 검증.
  12. 실기기 UI 검수 수용: 실기기 UI 검수가 필요한 작업은 PM의 눈 확인(Visual Acceptance) 전 미종결.
  13. 불확실성의 UNKNOWN 명시: 정확히 확인되지 않은 사실이나 시간, 원인은 UNKNOWN으로 표기.
  14. 역사적 기록 보존: 과거 오류 및 실수 기록은 삭제하지 않고 SUPERSEDED/RESOLVED로 남김.
  15. 관제실과 생산 앱의 독립성: Production 백엔드/앱 런타임은 관제실 코드에 실행 의존성을 가지지 않음.

  17. 무관 기능 보호 (MUST_NOT_TOUCH): 작업 비대상 기존 기능(MUST_NOT_TOUCH)은 100% 사이드이펙트 보호.
  18. 본선 개발 촉진: 안전 검증 통과 시 관제실 확장을 멈추고 본선 개발(MAP/SPATIAL 등)로 즉시 복귀.
