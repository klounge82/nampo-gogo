## 1. 비밀 자산 보안 취급 규정
본 서비스의 Release 서명키, 비밀번호, API 키, 서비스 계정 정보는 외부 노출 시 심각한 보안 침해를 유발할 수 있으므로 다음 규정을 철저히 준수합니다.

1. **Git 버전 관리 저장소 커밋 절대 금지**:
   - `key.properties`, `*.jks`, `*.keystore`, `*.pem`, `*.p12`, `*.key` 파일은 Git 저장소에 절대로 추가하거나 커밋하지 않습니다.
   - 프로젝트 `.gitignore` 파일에 해당 확장자들이 항상 엄격하게 등록되어 있는지 검증합니다.
2. **로그 및 보고서 평문 출력 금지**:
   - 커맨드라인 실행 로그, 빌드 스크립트, 마크다운 문서, 커뮤니케이션 채널에 서명키 비밀번호 원문을 절대 남기지 않습니다.
3. **로컬 디스크 영역 분리**:
   - 서명키 파일(`nampo-gogo-upload-key.jks`)은 프로젝트 Git 코드 경로(`D:\dev\Nampo_GoGo_Project`)가 아닌 로컬 사용자 외부 안전 폴더(`C:\Users\Master\NampoGoGo_Keys\`)에 보관합니다.
