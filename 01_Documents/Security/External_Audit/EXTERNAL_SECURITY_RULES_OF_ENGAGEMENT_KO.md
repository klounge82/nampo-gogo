# 남포고고 외부 보안진단 수행 수행 규칙 및 안전 지침서 (EXTERNAL_SECURITY_RULES_OF_ENGAGEMENT_KO)

**작성일자**: 2026-08-02  
**적용 대상**: 외부 보안진단 전문업체 및 모의해킹 수행자

## 1. 개요
본 규칙서(Rules of Engagement)는 외부 전문 진단자가 남포고고 모바일 앱 및 백엔드 서비스를 진단하는 과정에서 실제 운영 데이터 파괴, 서비스 중단, 개인정보 유출을 방지하기 위해 준수해야 할 필수 규정과 제한사항을 정의합니다.

---

## 2. 절대 금지 사항 (Strictly Prohibited Actions)

진단 수행자는 아래의 어떠한 행위도 운영 및 Staging 환경에서 수행해서는 안 되며, 위반 시 진단 즉시 중단 및 법적 책임이 발생할 수 있습니다.

1. **서비스 거부 공격 (DoS / DDoS / Traffic Flooding)**:
   - 무차별 대량 패킷 전송, 서버 성능 저하를 유발하는 트래픽 폭주 시도.
2. **자동화 무차별 대입 (Automated Brute-Force)**:
   - 초당 수십 회 이상의 로그인/인증 코드 대량 자동 대입 공격.
3. **운영 데이터 파괴 및 변조**:
   - 운영 DB에 대한 `DELETE`, `TRUNCATE`, `DROP`, `UPDATE` 직접 수행.
   - 실제 매장, 실제 고객의 예약/리뷰 정보 삭제 또는 임의 상태 변조.
4. **실제 고객 계정 도용 및 접근**:
   - 남포고고 실제 사용자의 계정 로그인 시도, 개인정보 조회/다운로드.
5. **클라우드 / 코드 저장소 인프라 공격**:
   - Railway PaaS 관리자 콘솔, GitHub 저장소, DNS 레코드에 대한 공격.
   - 운영 서버 비밀번호, SSH Key, DB 비밀번호 탈취 시도.
6. **제3자 인프라 공격**:
   - Kakao, Naver OAuth, Firebase Messaging, Google Maps API 등 연동 제3자 서버 대상 공격.
7. **사회공학 기법 및 물리 침입**:
   - 임직원 대상 보이스피싱, 스미싱, 이메일 피싱 및 사옥 물리적 침입.

## 3. 테스트 속도 및 트래픽 제한 (Rate Limits & Thresholds)

운영 환경의 안정성을 위해 진단 시 다음 제약 수치를 엄격히 준수해야 합니다.

| 점검 영역 | 허용 최대 속도 / 횟수 | 비고 |
| :--- | :--- | :--- |
| **HTTP Request Speed** | **초당 1 ~ 2회 이하** (Max 2 req/sec) | Burp Suite / OWASP ZAP Rate Governor 적용 |
| **Concurrent Requests** | **최대 3개 동시 연결** (Max 3 threads) | 멀티스레드 대량 스캔 금지 |
| **로그인 실패 시도** | **계정당 최대 10회 제한** | 연속 실패 후 중단 |
| **테스트 데이터 생성** | **계정당 최대 예약 5건, 리뷰 3건** | 무분별한 데이터 쌓기 금지 |
| **파일 업로드 시도** | **테스트당 최대 10개 파일** | 10MB 이하 파일로 제한 |
| **진단 시간대** | **평일 10:00 ~ 18:00 (KST)** | 담당자 상주 시간대 전용 |

## 4. 진단용 User-Agent 및 IP 사전 등록

1. **사용자 식별자(User-Agent) 설정**:
   - 진단 중 발생하는 모든 HTTP/HTTPS 요청에는 다음 헤더를 반드시 포함해야 합니다:
     `User-Agent: NampoGoGo-SecAudit-VendorName/1.0`
2. **진단 IP 사전 등록**:
   - 진단 수행자의 고정 공인 IP 주소를 사전 제출해야 하며, 미등록 IP에서의 진단 시도는 WAF/防火牆에 의해 차단될 수 있습니다.
