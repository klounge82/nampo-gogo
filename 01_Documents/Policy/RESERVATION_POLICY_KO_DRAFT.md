# 남포고고 예약 및 취소 운영정책 (초안)

> **시행일자**: 2026년 8월 20일  
> **버전**: v1.0

본 정책은 남포고고 서비스 내 매장 예약 신청, 승인, 거절, 취소, 이용 완료 및 노쇼 처리 기준을 규정합니다.

---

### 1. 예약 상태 정의

남포고고 서비스 내 모든 예약은 다음 7가지 상태로 엄격히 관리됩니다:

| 한글 표기 | 시스템 상태 코드 | 설명 |
| :--- | :--- | :--- |
| **승인 대기** | `PENDING` | 이용자가 예약을 신청하고 매장의 승인을 기다리는 상태 |
| **예약 승인** | `APPROVED` | 매장(사업자)이 예약을 확인하고 승인한 상태 |
| **승인 거절** | `REJECTED` | 매장(사업자)이 사정에 의해 예약을 거절한 상태 (거절 사유 제공) |
| **이용자 취소** | `CANCELLED_BY_CUSTOMER` | 이용자가 직접 예약을 사전 취소한 상태 (취소 사유 제공) |
| **매장 취소** | `CANCELLED_BY_BUSINESS` | 승인 후 매장 사정으로 부득이 취소한 상태 (취소 사유 제공) |
| **이용 완료** | `COMPLETED` | 예약 시간에 맞춰 매장을 정상 방문하여 서비스를 이용 완료한 상태 |
| **노쇼** | `NO_SHOW` | 사전 취소 없이 예약 시작 시각 후 15분이 지나도록 방문하지 않은 상태 |

---

### 2. 예약 시간별 처리 제한 규칙

1. **미래 예약 이용 완료 차단**:
   - 예약 시작 시각(`reservation_date` + `start_time`) 이전에는 사업자가 해당 예약을 [이용 완료] 처리할 수 없습니다.
   - 조기 완료 시도 시 시스템에서 HTTP 400 (`RESERVATION_NOT_STARTED`) 오류로 자동 차단됩니다.

2. **노쇼 유예시간 15분 적용**:
   - 예약 시작 시각으로부터 최소 15분이 경과한 이후부터 매장에서 해당 예약을 [노쇼] 처리할 수 있습니다.
   - 15분 도래 전 노쇼 처리 시도 시 시스템에서 HTTP 400 (`NO_SHOW_GRACE_PERIOD_NOT_ELAPSED`) 오류로 자동 차단됩니다.

3. **Legacy (시간 미정) 예약 처리**:
   - 날짜/시간 정보가 누락된 구형 예약건은 처리 버튼이 차단되며 "예약 시간이 확인되지 않아 처리할 수 없습니다." 메시지가 안내됩니다.
